# ArmageddonSeeder

Inherits the repository instructions. Open `ArmageddonSeeder.sln` for optional Armageddon work. Preserve package names, question IDs, stable ownership keys and the Worldfile package's question-free one-shot contract. Original ArmSolo source and data remain external; never embed them or copy them into this repository. Distribution is by local packaging only; do not register this product on the website or upload public release binaries.
