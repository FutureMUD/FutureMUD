# Seeder module instructions

Inherits the [repository instructions](../../AGENTS.md) and [DatabaseSeeder instructions](../AGENTS.md).

Keep a seeder and its private partials/helpers in `Seeders/<SeederClassName>/`; shared helpers belong in `Seeders/Utilities/`. Apply the project rules for honest repeatability, stock ownership, answer reuse and explicit prerequisites.

For clan templates, clan-related supporting progs, or template-clone semantics, read [ClanSeeder instructions](ClanSeeder/AGENTS.md). The clan terminology, elections and organisation-design rules there do not apply to other seeders.

For emitted text, load the relevant [character-description](../../Design%20Documents/Markup/Character_Description_System.md) or [human-seeder pattern](../../Design%20Documents/Markup/Human_Seeder_Description_Patterns.md) reference only when that markup is involved.
