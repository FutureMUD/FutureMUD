# Armageddon Magic

This is the setting-specific magic documentation. Engine-generic casting, powers, resources and lifecycle contracts remain in the [Magic index](../../Magic/README.md).

The whole programme remains incomplete and disabled; a completed adapter or native checkpoint does not imply full catalogue/release qualification. ARM-01 casting proposals retain unsettled owner decisions.

Current contract sections own behavior. Dated receipts retain their stated revisions, failed/unexecuted checks and local artifact limitations. File dates alone do not establish implementation status.
