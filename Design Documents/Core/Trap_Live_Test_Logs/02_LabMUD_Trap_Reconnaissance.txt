Tagline: Automatically generated help for the traptemplate command

This command creates reusable templates for mechanical, magical, and natural
traps. A template contains one or more triggers and payloads. A deployed trap
pins the approved template revision that it was created from.

Use the following options:

  traptemplate list [+keyword, -keyword] - lists trap templates
  traptemplate show <which> - shows a template
  traptemplate edit <which>|new - edits a revision or creates a template
  traptemplate edit submit|close|delete|obsolete - manages the edited revision
  traptemplate review all|mine|<which> - reviews a template
  traptemplate set name <name> - renames this template
  traptemplate set domain mechanical|magical|natural - selects its source domain
  traptemplate set trigger add <type> - adds an OR trigger; use trigger remove
<number> or trigger <number> parameter <name> <value> to configure it
  traptemplate set payload add <type> - adds an ordered payload; use payload
remove <number>, payload <number> delay <timespan>, payload <number> target
<selector>, or payload <number> parameter <name> <value> to configure it
  traptemplate set charges <number> - sets uses before the trap is spent
  traptemplate set cooldown <timespan> - sets reset time between successful
triggers
  traptemplate set disarm impossible|safe|risky|dispellable - sets disarm policy
  traptemplate set lifecycle indefinite|fixedexpiry <timespan>|unstable
<timespan> - sets lifecycle policy
  traptemplate set validate - reports readiness errors

Each trigger and payload accepts named parameters. The builder display records
all configured parameter names and values, allowing source-specific runtime
services to evolve without changing the editable revision workflow.

Tagline: Automatically generated help for the gas command

The gas command allows you to create and edit gases and their properties. These
gases in turn can be used by items, characters and other effects.

The syntax for this command is as follows:

  gas list - Lists all gases
  gas show <which> - shows information about a gases
  gas edit <which> - begins editing a gas
  gas edit - same as material show for your currently edited gas
  gas clone <which> <new name> <new description> - clones a gas
  gas new <name> - creates a new gas
  gas set organic - toggles counting as organic
  gas set description <description> - sets the description
  gas set density <value> - sets density in kg/m3
  gas set electrical <value> - sets electrical conductivity in siemens
  gas set thermal <value> - sets the thermal conductivity in watts/kelvin
  gas set specificheat <value> - sets the specific heat capacity in J/Kg.Kelvin
  gas set colour <ansi> - sets the display colour
  gas set drug <which> - sets the contained drug
  gas set drug none - clears the drug
  gas set drugvolume <amount> - sets the drug volume
  gas set viscosity <viscosity> - sets the viscosity in cSt
  gas set smell <intensity> <smell> [<vague smell>] - sets the smell
  gas set countsas <gas> - sets a gas that this counts as
  gas set countsas none - clears a counts-as gas
  gas set quality <quality> - sets the maximum quality of the gas when

  gas set condensation <temp>|none - sets or clears the temperature at which

  gas set liquid <liquid>|none - sets or clears the liquid form of this gas
