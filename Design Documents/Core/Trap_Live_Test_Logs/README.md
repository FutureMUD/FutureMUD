# LabMUD Trap Live-Test Logs

This directory contains redacted raw transcripts generated by the FutureMUD MUD tester for the LabMUD trap-system acceptance exercise. The local fixtures are intentionally retained at the requester's direction; the acceptance report records their final identifiers and runtime state.

Start with [LabMUD_Trap_Acceptance_Report.md](LabMUD_Trap_Acceptance_Report.md). It links the original key builder, layer, triggerer, recovery, and final-state transcripts. Files 1-93 are complete raw session transcripts produced by the tester unless explicitly described below; passwords are redacted by the test harness. Files 94-96 are concise acceptance extracts for the exit/UX follow-up, preserving the commands and decisive outputs without repeating login banners and room descriptions.

`38_LabMUD_Tripwire_Explosive_Triggerer_Interrupted.md` is the only non-raw record. The client connection was reset before the harness could flush its normal transcript, so that file plainly records the lost-session limitation and the surviving evidence.

Files 97-103 cover the 12 August physical-component follow-up. They deliberately retain the two fixture/keyword failures and the interrupted-resolution defect that live testing exposed, followed by the corrected runs. [104_LabMUD_Physical_Component_Acceptance_Report.md](104_LabMUD_Physical_Component_Acceptance_Report.md) is the concise index and final disposition; 98 is the successful builder flow, 99-100 are fixture-targeting diagnostics, 101 first proves binding/reservation/detonation, 102 proves spent recovery while exposing the reboot residue, and 103 proves both load-time repair and clean same-session removal after the lifecycle patch.
