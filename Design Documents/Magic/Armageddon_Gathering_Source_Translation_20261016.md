## Native translation boundaries

`MagicGatheringMethodDefinition` already supports exact six-argument damage, stun, stamina and duration progs. Land shares bodily planning/payment with Self and has native source accounting. Preserve those guarded payment and durable receipt paths. FutureProg `gettrait` reads effective proficiency; a casting capability's concentration trait is not automatically Gather.

The exact cellular-wound planner now supports both `SimpleLivingHealthStrategy` and `ComplexLivingHealthStrategy`, including the standard seeded full human model. Complex planning excludes bone targets. Native modifiers, capacity limits, severity limits, existing-wound updates and durable payment checks remain; unsupported strategies refuse. Pure `healthcapacity` / `healthremaining` FutureProg functions expose current-body maxima and remaining health, stun, pain and stamina. Stock damage uses one native health unit per source HP unit; stun and stamina use the source price divided by native maximum HP, multiplied by their respective native maxima. Preserve one remaining HP and clamp stun/stamina at zero, after checking affordability. Source pain narration does not create an independent native pain charge.

The environmental coordinator owns room-local sources and persistent scars. The original regional life stock and fallback plant flags are not identical to agriculture yield scores. A minimum meaningful v1 adaptation can debit a configured real native life/yield owner per action, but must document the regional-to-local and stock-unit translation, and distinguish temporary ash appearance/cost from lasting ecological depletion. There is no approved positive ambient production pool. Profile authoring must not automatically assign existing rooms or invent vegetation.

The earlier 10/min Self and 20/min Land suggestion is superseded by the recovered delay semantics, not installed. Source `skill_data.delay` is the first value after the function pointer (166906-166919): Gather's value is zero (175911-175915), and generic dispatch applies `PULSE_VIOLENCE * delay` (173340-173353). The adjacent15 is `start_p`, not a positive action delay. The handler has no explicit wait.

Ash uses heap event units. `WAIT_SEC=12` (25055), `OPT_USEC=250000` (168123), and the real-time loop uses that opt_time and select wait (168957-169036). The normal driver adds four heap ticks every12 loop pulses (169286-169290), giving a nominal0.75 real seconds per heap tick and nominal270 real seconds per mana for ash. This is a derived normal-speed target, not a guaranteed measured wall-clock duration or an assumption that one event unit is one second. Debug runfast and scheduler jitter are not preset timing units.

Alignment's Gather affect uses a separate explicit wall clock: `RT_ZAL_HOUR=600` (24979); `affect_to_char` sets expiration to initiation plus600*duration-1 seconds (49435-49440), with expiry tested against Unix time (172610-172642). It therefore suppresses repeated alignment changes for10-90 real minutes, while ash expiry does not restore the ecological stock. Stock callbacks use these explicit UTC durations. Ash is a single persistent native description addendum whose pure applicability prog hides it after expiry; expiry does not heal life or scar. A source-style dissipation broadcast is not implemented.
