# Armageddon reviewed provision installer integration

This bounded checkpoint extends the independently reviewed partial source-tradition installer. It adds Sustain Meal and Draw Wine definitions through a separate seven-record module and makes Hovering Light reachable through the historical food branch. It is a programmatic content API, not an enabled interactive installer or a complete Armageddon preset. The central completion ledger and repertoire tables remain unchanged.

## Reruns and durable failure

Content and ownership commit atomically in one serializable native transaction. Stable keys, logical IDs and three-way field baselines preserve builder renames, definition/profile edits and cost edits; clones stay unowned. Definition is a whole owned scalar: an explicit builder XML override remains that override on rerun, including its admissions or profile choices. Missing or retired owned rows and competing ownership claims block the whole module without resurrection. Profile/recipe ordering is canonicalized for binding receipts while food pool order is preserved.

A pre-commit failure rolls back all seven records. Lost confirmation after an acknowledged commit reports CommittedConfirmationFailed; a fresh-context/process rerun resolves the same identities. A commit exception without acknowledgment reports CommitOutcomeUnknown and requires reconnect/rerun. Installation does not attach merits, enrol actors, grant openings, refill reserves or update player/acquisition/consumption state. Existing authored enrolment and native skill-use reconciliation perform the progression.
