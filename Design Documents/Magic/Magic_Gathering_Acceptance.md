# Capability-configured gathering acceptance map

This map covers the 14 functional (`G-T`) and 12 environmental integration (`G-I`) rows for Self and Gentle gathering, plus the 40 destructive Land (`L-T`) regressions and six native probes (`L-P`). A mapping describes checked-in coverage, not a claim that a fixture proves a network or power failure. The implementation report states automated and disposable-database evidence separately.

## Test boundaries

| Label | Primary source and boundary |
| --- | --- |
| `Gathering` | [MagicGatheringServiceTests](../../MudSharpCore%20Unit%20Tests/MagicGatheringServiceTests.cs): real environmental coordinator, cells, resources, monotonic clock, source debit and command trees; world facade, receipt store and selected persistence boundaries are controlled test substitutes. |
| `Health cost` | `SimpleLivingDirectHealthCostTests` exercises the concrete `SimpleLivingHealthStrategy` and `SimpleOrganicWound` planner/application path against controlled body/world interfaces. `Gathering` rows exercise captured plans, tracked wound objects and the bounded persistence boundary with controlled service/save collaborators. A disposable live database/restart walkthrough remains separate acceptance evidence. |

| `Prog` | [MagicFutureProgFunctionTests](../../MudSharpCore%20Unit%20Tests/MagicFutureProgFunctionTests.cs) and `Gathering.CompiledPostGatherProg_RunsOnceAndIsFlushedBeforeDurableCompletion`: registered script surface and a real compiled post-gather FutureProg; its register/save facade is controlled. |
