# Security review summaries

The dated CSV is an archival public summary containing finding titles, severity and subsystem grouping. It is not the current security backlog.

Detailed audit descriptions, exploit procedures, finding links, cloud scan identifiers, assignee details and patch/status metadata belong in the private security tracker or an ignored local working artifact. Keep them out of tracked public exports while remediation is in progress.

Redacting the current export does not remove copies already published in Git history. This change does not rewrite repository history.
