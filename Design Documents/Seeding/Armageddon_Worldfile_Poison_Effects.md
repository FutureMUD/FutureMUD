# Armageddon worldfile poison effect mapping

## Scope

This slice creates ten calibrated native toxin definitions, reusable staged symptoms and permanent trait consequences, a native poison resistance check, and generated duration-to-dose progs. Source-authored food, drinks, edible herbs, laced spice, oral antidotes, weapon coatings, darts and poison-vial application have delivery interactions. The consequences/cleansing follow-up adds source-backed HP/recovery policies, ordered character cures and object cleansing; the existing magical toxin's own pharmacology remains native.

The user approved **one milligram per source duration unit**, source sleeping lethality, permanent Wisdom losses, and a native Endurance-based poison saving throw. The mass conversion is authored game data, not a recovered source measurement. Poison value 1 remains a nominal amount that the audited coating path does not use as a dose.

## Source timing and effects

`utility.c:840–972` constructs the source effects; `limits.c:1175–1816` supplies poison-specific updates. `sp_parser.c:926–974` dispatches updates while effects remain active. A duration argument is a Zal-hour, **600 real seconds** (`core_structs.h:53`, `handler.c:937–951`), rather than one poison update. Peraine halves the supplied duration; plague forces its default 50 Zal-hours. Source poison probabilities are evaluated by the frequent character-update path, separately from duration expiry.

The actual nominal source update cadence is **three real seconds**: the loop targets 250,000 microseconds per pulse (`socket.c:61,869–870`), and `WAIT_SEC` is twelve pulses (`core_structs.h:129`, `socket.c:1195–1200`). The native toxin profiles therefore use three-second symptom trials, processed by the existing ten-second drug heartbeat. Earlier one-second interpretation was corrected before this calibrated tranche.

Names/indices come from `constants.c:2672–2685`. Index zero means no poison. Ownership records use `poison.drug.<index>` and retain the native drug ID. Pharmacology records are not individual item prototypes; imported items retain their Vnum unique names.

The symptom engine accumulates active elapsed time and evaluates trials at each profile's interval. Messages and consequences can arrive in a short batch. It never processes offline poison time or catches up a long stall. Native absorption, body mass, metabolism, resistance and neutralisation remain the outer drug model. Constant source-style episode formulas remain constant while effective intensity is positive; builders can include `intensity` for dose-dependent episodes.

## Approved dose calibration

Each supplied duration unit maps to 0.001 grams. At the reference liver-removal rate of 0.01 kg/hour, relative metabolism 0.0006 removes 0.0000166667 grams per ten-second native heartbeat, so one milligram corresponds to ten real minutes of active clearance. Intensity per gram is 70: one active milligram has unit intensity at 70 kg. Native vector absorption and physiology remain active; this is not an exact fixed lifetime for every character. Partial latent absorption is capped at the actual remaining mass, preventing the old minimum absorption amount from manufacturing extra toxin.

| Source administration | Duration before poison-specific defaults/halving | Calibrated payload |
| --- | --- | --- |
| Primary melee hit | Random 1–4 | 1–4 mg |
| Secondary melee hit | Random 1 to 27 minus victim Endurance | Approved uniform nominal 1–4 mg |
| Backstab | 2d4 | Approved uniform nominal 1–4 mg |
| Thrown poisoned weapon/dart | Random 1 to 27 minus **thrower** Endurance | Approved uniform nominal 1–4 mg |
| Food | Twice source remaining food units | Approved adaptation: 2 mg per original food unit, prorated by the amount eaten |
| Drink | Three times source units actually drunk | 3 mg per source 50 mL; 0.06 g/L for a native fluid mapping |
| Special sip | 3 | 3 mg |
| Edible herb marked poisonous | 1, always generic poison | 1 mg; do not activate unused herb value 3 |
| Sniffed/smoked laced spice | Random 1–2, independently of spice potency | 1–2 mg through the inhaled vector |
| Poisoned sweets | 1 | 1 mg |
| Cure side-effect poison | Source random 1–3 | 1–3 mg; future cure interactions can suppress the saving throw where source does not roll one |

Generated `ArmageddonWorldfilePoisonDose<index>(actor, units, vector, save)` progs apply these common poison-specific rules: Methelinoc defaults a zero argument to fifty units; plague always uses fifty units and refuses a duplicate active or latent dose; peraine integer-halves the supplied units. A halved-to-zero peraine exposure is rounded to one native ten-second quantum, preserving a fleeting paralysis instead of discarding it. Other zero-duration profiles produce no lasting dose. Their source zero-duration onset edge cases are not inferred for unconnected routes.

Peraine's paralysis relative intensity is 60, making a reference body's final ten-second dose quantum exceed the native 0.75 threshold. Terradin's nausea relative intensity is five; actual nausea/vomiting uses native physiology. These are explicit effect calibrations rather than recovered physical properties. Native time quantisation and vector absorption can shift apparent onset/clearance by heartbeats. Native repeated doses add remaining exposure; the source's re-joining of stored durations can re-add elapsed time and is not copied.

## Saving throws and permanent consequences

`PoisonResistanceCheck` is appended as check ID 244. Basic and detailed skill seeders create an Endurance/Constitution-based `endurance * 5` standard check without trait improvement. The worldfile importer also supplies a missing check. Runtime bootstrap uses the same physiological defaults for an old database missing this check, rather than the loader's generic 50% improving-skill fallback. Existing configured checks are preserved. Worlds with unrecognised attribute names receive a zero formula that builders must bind explicitly. `resistpoison(character, difficulty)` runs that check; true means resisted. It does not dose or purge anything, and a body change during the check aborts the calling prog. This deliberately uses native rules rather than importing Armageddon's guild saving-throw tables. Passive native drug resistance still scales any accepted dose.

The generated dose prog's `save` flag controls whether to roll first; laced spice passes true. Half-giant recipients are refused for all three skellebain indices when the imported Half-Giant race is available, retaining source immunity without inventing a new resistance system.

Permanent consequences configure a trait, chance formula, signed amount and minimum raw value. Per-dose onset runs synchronously on accepted administration, before absorption; each dose gets its own roll and a later cure cannot undo an applied loss. The alternative default mode runs once on first active exposure. Natural-expiry consequences run only when metabolism removes the last positive active/latent dose. Explicit cure, selective purge and staff sobriety do not invoke natural expiry. Changes use native `TraitRawValue`/`SetTraitValue`, preserving owner scope and normal persistence without incorporating temporary bonuses. Callback body changes, death and onset cure stop further onset changes.

## Reusable capability

`DrugType.Symptoms` is appended as persisted value 28. Its profile is JSON in the existing intensity payload column; no schema migration is needed. A profile has a trial interval, optional resistance trait, initial stage, permanent onset/expiry consequences and stage list. Stages supply probability, damage/pain/stun/stamina formulas, native damage type, private sensory messages, optional awake-only processing, optional sleeping lethality, and transitions to configured stages.

Formula inputs are `intensity` (effective drug intensity per body mass), `resistance` (configured current trait), `fullness` (food-satiated hours), `sleeping` and `unconscious` (0/1), and `stage` (zero-based). Episode/transition probabilities are per configured trial, clamped to 0–1. Destination weight formulas default to one; skellebain uses Endurance-weighted improvement/worsening. Physical amounts are nonnegative and per successful episode. Invalid/nonfinite results become zero. Damage uses passive wounds; stamina uses native expenditure. Sensory messages do not create entities or real attacks.

One saved body-owned `DrugSymptomEffect` retains each drug's stage and onset/activation markers. Reconciliation updates intensity; only the heartbeat advances episodes. Cure and inspection cannot inflict extra symptom damage. Temporary neutralisation makes symptoms dormant while positive physical doses remain, avoiding repeat onset rolls when suppression lifts. Clearing the last physical dose removes stage state. Restart restores stage/markers with a fresh clock. Native doses remain authoritative exposure persistence.

Existing types still own paralysis, nausea/vomiting, trait modifiers and other supported physiology. Symptoms do not replace drug resistance, custody, damage or cure systems.

## Poison consequences and cleansing

Generic poison adds a separately timed maximum-HP penalty equal to each episode's actual rolled damage, for 5,400 real seconds. Penalties stack and survive clearance of the active drug. The existing effect scheduler owns their timers; `TimedMaximumHitPointsEffect` persists the signed bonus, source drug/family and capacity-only policy. Native imported Vampire race identity (source race 18) suppresses generic-poison symptom episodes. This is a source-backed immunity, not a newly invented undead race.

The approved optional `BrainHitpoints` configuration avoids counting the pulse twice: `SeparateCapacityPenalties` treats explicitly marked negative capacity modifiers as healing ceilings while damage still uses the underlying HP budget. For example, a 100-HP character receiving five damage and a five-point cap penalty has 95/95 HP. Healing cannot erase that five-point deficit while the cap remains; expiry or cleansing produces 95/100 rather than granting free current HP. Lethality still follows actual accumulated damage, even when the displayed cap reaches its native minimum. Prompts, health percentages, critical injury and wound penalties share the adjusted accounting. Common damage setters enforce the healing ceiling for HealingSimple, Simple, SimpleOrganic and BoneFracture wounds, including compatible retained wounds after body-form changes. The option defaults off in other games.

`UseStun` optionally adds native stun to the HP model without enabling complex health. HealingSimple wounds now preserve stun using the existing database field, retain stun-only wounds, and use configurable maximum-stun and recovery expressions. Reaching the stun limit yields native unconsciousness and honours native stun-unconsciousness prevention. `UseCellularDamage` separates poison/cellular damage from heart simulation; old definitions default to their former heart-check behaviour. The worldfile installation opts its Human HP strategy and derived NPC strategies into these options, reusing the installed human stun expressions (constant-100 fallbacks if absent). Other health strategies retain their configuration.

Heramide uses the approved natural-recovery block **only while unconscious**. The reusable effect contract is checked by active and offline wound stun recovery, while explicit/magical healing remains possible. Effective symptom intensity is saved so offline recovery cannot bypass an active block before reconciliation; neutralisation makes it dormant. Grishen uses native sprawled posture and sleep when an exhaustion episode finds stamina already exhausted. Peraine adds an opt-in native paralysis policy that uses selective combat cessation, clearing the victim and incoming targeting without ending unrelated combatants' fight.

Character Purge Toxin uses configurable ordered drug families, removing the first present family per cast. Magical poison precedes mundane generic poison, followed by Grishen, the complete Skellebain family, Methelinoc Toxin, Terradin, Peraine, Heramide and Plague. Native prepared selections retain the chosen family and physical body through casting. Only selected doses, matching poison effects and opted-in independently timed aftereffects are removed; unrelated medicines/drugs remain. Permanent losses already applied are not reversed and natural-expiry penalties are not triggered.

Kelwin's private cure retains the approved explicit native venom list and additionally admits the source generic, Grishen, complete Skellebain, Terradin, Peraine and Heramide families. It does not gain Methelinoc Toxin or Plague coverage. His Blackwing, healing threshold and native spell-service rules remain. The Halfling healer remains magical-poison-only. Generic-poison cure vials and spells clear the lingering HP penalties; tablets deliberately leave them behind, matching the source distinction. Neither route heals the wounds themselves.

`Cleanse Poisoned Object` is a native item-targeted version of the installed Purge Toxin spell, sharing its school, knowledge rules, casting policy and costs. Its prog removes weapon/dart coatings, clears imported food poison and restores clean beverage lineages without consuming volume or changing freshness. Closed vessels are allowed; unmapped constituents are preserved. Source spice is not a cure-poison object target. Reusable `removeweaponpoison(item)` and extended `remapliquids` flags implement those operations; no foreign script interpreter or parallel consumption system is added.

## Oral delivery and reusable administration policy

Native drugs expose independently combinable `DoseBehaviour` flags: `FixedDose` normalises each positive administration to `FixedDoseGrams`, while `IgnoreAdditionalExposure` refuses further administrations while positive active or latent doses of the same drug remain. `Normal` preserves existing mass-based behaviour. These policies apply in the body admission path to ordinary and immediate delivery; they do not depend on a symptom type, source index or name. Builders configure them using `fixeddose <grams>` and `dosebehaviour <flags>`; progs can inspect `dosebehaviour`, `fixeddosegrams` and `fixedadministration`. Plague opts into both flags with a fixed 0.05-gram payload. Zero/invalid delivery amounts do not manufacture an exposure.

Imported food uses native fractional bites and an `ItemEaten` hook, which executes before exhausted food is deleted. Its total payload is 0.002 grams times original source food units. Poisonous edible herbs supply generic poison at 0.001 grams per item. Poisoned beverages use cloned native liquid lineages with unchanged presentation, physics, original drug and existing draught callbacks; an additional draught callback administers 0.06 grams per litre actually consumed. Native transfers, dilution and freshness retain the toxin lineage. These proportional routes retain poison saves, Skellebain half-giant immunity and Peraine's half-dose rule; the drug-level fixed-dose policy supplies Plague's exception.

Antidote tablets and vials use native oral consumption through a Pill component and optional builder-configurable consumption emote. The `swallowitem(character,item)` prog helper retains native access/anatomy checks, character-state restrictions and general action blockers. Generated `eat`/`drink` command hooks only handle the specific held antidote. Cure indices 3, 9 and 10 clear all three Skellebain definitions, including latent doses; other supported indices clear their exact toxin. Index zero intentionally cures nothing. Source side-effect poison is administered without a saving throw. Vials leave the available empty Vnum13248; source strength fields remain unused. No native wounds are healed, and removing a dose by antidote does not trigger its natural-expiry penalty.

`remapliquids(item, fromIds, toIds)` provides reusable atomic lineage replacement, preserving quantity, freshness and specialised liquid-instance metadata. It refuses closed containers, invalid targets or incomplete mappings without changing their contents. Poison-vial application uses this helper.

## Weapon coatings, darts and vial application

The approved adaptation uses a uniform random nominal **1–4 mg** on every qualifying weapon/dart hit, replacing source offhand/backstab/throw-specific amounts. Existing toxin-specific rules still apply: Peraine halves duration/dose and Plague uses its configured fixed 50 mg non-stacking administration policy. The native Endurance-based poison save applies to hit exposure; a resisted or already-present exposure still spends the coating.

`WeaponPoisonCoating` now optionally stores a delivery prog and a single-use flag. The ordinary liquid coating defaults, evaporation, capacity and delivery probabilities remain unchanged. The scripted policy is persistent and non-evaporating, with no fabricated carrier liquid. `setweaponpoison(item, deliveryProgId)` attaches it to one uncoated native melee weapon or ammunition item; the prog takes `(attacker, victim, weapon)` and owns dosing/saves. `hasweaponpoison(item)` identifies either coating kind. The combat helper selects an actual damaging wound using native injected-poison eligibility, checks that the wound still belongs to the character's current body, removes a single-use policy before invoking it, and invokes it once even when a hit creates multiple wounds. Misses, fully absorbed hits, nonphysical targets and ineligible wound types do not spend it.

Native throwing now invokes that same helper after physical wound processing, including lodged darts. All retained source type-24 darts import as native piercing `ThrownWeapon` items: source plus/dice/sides supply damage, a copied Knife profile supplies melee use, and the installed native throwing profile supplies throwing skill/range/timing. Dart value 3 remains poison identity, never a weapon attack type. The source archive has no initially poisoned dart definitions; vials can poison them in play. Native throwing must exist at preflight, and permanent shop stock receives the correct unwielded thrown-item state.

The effect saves its policy ID/flag and preserves them on morph. When ammunition creates separate projectiles, a single-use charge transfers to the first projectile only, rather than multiplying across a multi-projectile round. Stack splitting likewise transfers a single scripted charge instead of dividing or duplicating it; application requires quantity one and the effect prevents merging. Source-authored initial weapon coatings receive both on-load policies and direct persisted opening-stock effect data.

Players use `poison <held item> [with <held vial>]`, quoting multi-word targets. A weapon may also be wielded. Without `with`, the first held source poison vial is selected. Native manual-action/access, able-state and general-action-blocker checks run before application. Weapon applications reject source bludgeon/chop types, weapons above the source 600-weight-unit limit, already coated targets and unsplit stacks. They use native `ApplyPoisonToWeapon` through reusable `actioncheck(actor, checkType, difficulty)`. A failed weapon application consumes the vial and attempts a saved four-unit self-exposure; a successful application attaches the single-use coating. Darts use the source's unchecked nonweapon application branch, with native single-item/coating restrictions.

Food/spice application replaces the item's poison-kind register. Drinks replace every supported beverage lineage atomically using `remapliquids`, retaining native volume, freshness, dilution and the original beverage's drug/callback properties. Re-poisoning replaces the previous toxin lineage rather than stacking clones. Closed/empty/unsupported containers and other refused targets leave the vial intact. Successful applications consume the whole vial; the source nominal amount field remains unused. Invalid source poison indices remain inert provenance. Shaving a laced spice loads the source pinch prototype without copying the brick's poison, matching the source `cmd_shave` behaviour.

`canmanipulateitem(actor,item)` is a reusable pure admission query around native manual manipulation, character-state and action-blocking rules. `actioncheck` uses the installed check's existing trait, difficulty and improvement policy and aborts on invalid/changed physical actors.

## Plague infection mapping

Plague Toxin remains the exposure/cure identity, but now contains an Infection effect. Its separate Plague Symptoms definition supplies the existing agility penalty, fever/cough/sneeze symptoms and permanent one-point Wisdom loss on natural completion. A positive accepted exposure establishes one native whole-body configured infection, with exactly 30,000 active real seconds (500 minutes). The legacy fixed 50 mg exposure policy remains in delivery metadata, but no plague drug mass is stored or metabolised after establishing the illness. Subsequent exposures neither stack nor refresh the illness.

Source transmission occurs within a symptom episode, not independently of it: `limits.c:1217-1257` uses an episode chance of `1 / (min(abs(movement), 10) + 1)` and a one-in-10,000 roll for each room occupant. The import substitutes native current stamina for source movement in that formula and exposes `stamina` as a general symptom formula input. Successful three-real-second symptom trials invoke the infection's configured transmission. Each recipient gains the same fixed-duration infection, subject to duplicate refusal, with no invented physical dose. The source comment's 0.001 percent disagrees with its actual one-in-10,000 roll; the import follows the roll (0.01 percent).

Existing plague tablets, vials and the ordered Purge Toxin family select the exposure drug ID and clear the matching infection, including origin-family filtering. Cure suppresses natural-completion Wisdom loss; it does not restore permanent losses already incurred. Kelwin's existing exclusion of plague is unchanged. Native antibiotic/immune progression does not shorten this fixed-duration import policy. The infection machinery also supports native immune recovery for other definitions.

### Skellebain involuntary outcomes

Stage two includes a native sit and a witnessed hand-burning yelp; stage three includes sitting, cosmetic vomiting, bowel residue, babbling and grip loss. Hallucinated paralysis/fear remain descriptions, not invented paralysis or fleeing.

Readied equipment means native wielded equipment; general inventory and worn garments remain carried. Native drop rules still apply. Grip loss also removes the actor's native grapple with normal cleanup. Sitting uses native forced posture transition only from a higher position. Babbling uses the native speech restriction contract for 600 real seconds and does not refresh an existing babble effect (source `handler.c`, `RT_ZAL_HOUR=600`, duration one). Its timer persists independently of the poison, matching the separate source affect; curing Skellebain prevents new episodes.

The approved contamination adaptation clones the core feces material as a described, water-washable Worldfile bowel residue and deposits an authored 0.01 kg of native residue on the body and garments covering a wear location whose name contains `leg`.
