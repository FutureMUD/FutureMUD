# FutureMUD Renaissance Military, Firearms, and Armour Design Reference

## Scope and delivery status

This is the canonical source for the 1400–1600 Renaissance military item catalogue. It owns new forms whose silhouette, material, component profile, institutional use, or production context is specifically Renaissance. Earlier cross-era forms remain admitted through their existing `preindustrial_*` or earlier stable references; this catalogue deliberately does not duplicate them merely to add an era tag.

FutureMUD/FutureMUD#575 supplied the required item-component groundwork. The Renaissance branch therefore consumes the actual matchlock and wheellock muzzleloader, artillery, weapon-carrier, armour, shield, melee, and ranged profiles; it introduces neither runtime mechanics nor persistence changes. Artillery is in scope, including period field pieces, compatible shot, a swivel mount, and crew equipment.

### Prerequisite flow

`ItemSeeder` checks the complete canonical catalogue before it starts any item stage. A Renaissance selection fails closed when a required material, full tag path, or component profile is absent. Its rerun guidance specifically names Combat's weapons, ranged, and early-gun packages; it never installs a gun package that a builder declined. Once those packages and the normal UsefulSeeder foundations are present, rerunning Items is safe: rows are located by stable reference, repaired as stock metadata, and never legacy-matched by short description.

## Content rules

- SDescs are concise article-led product names. Full descriptions are authored verbatim from the table: three visible, form-focused sentences with no builder, seeding, component, or unsupported-mechanics language.
- Finished arms, armour, shields, artillery, and field gear are skinnable. Fungible ammunition is not. The row's builder notes carry its dated admission, source family, culture/institution decision, and exact component profile.
- The tags and component strings below are canonical maintained names. The generation check validates all of them against the material, tag, and component exports before it can write C# source.
- This is a form catalogue rather than a set of culture labels applied as decoration. The public text describes construction and handling; culture and institution appear only in admissions, tags, and builder notes.

## Culture and admission matrix

Every Renaissance culture cluster has an explicit outcome. A `new item` is a distinct form in the table, an `admission` is carried by an existing earlier reference, and a `skin` is appropriate only where the base component and silhouette are unchanged.

| Global maritime / contact overlay | New item | Swivel gun, signal equipment, powder containers, and compatible shot. |

## Explicit exclusions

- Handgonnes are not seeded because no supported handgonne handling profile exists.
- Flintlock dominance, percussion systems, revolvers, metallic cartridges, modern explosives, and modern naval ordnance are excluded.
- Coehorn-era equipment, post-1600-default patterns, uniforms, crafts, naval stores beyond artillery support, and new engine mechanics are separate work.
- Rifle is not a default Renaissance row; the wheellock long-gun profile remains available for an explicitly selected long-gun form only.
