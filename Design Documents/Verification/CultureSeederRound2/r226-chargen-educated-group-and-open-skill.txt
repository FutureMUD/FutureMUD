Skill Boosts

The next step is deciding whether to apply any boosts to your character's starting skills. This is a totally optional process, and costs build points. Each character also gets 25
free BP to spend on boosts, so even a first character can emphasise one key skill. Each skill boost will push your starting skill value up approximately one "rank". It is mostly
designed so that after the first few characters, when players have started to accumulate some build points, they can avoid some of the starting grind, but "troll" players who
consistently roll red-shirt characters to try and PK don't get the same leg up.
