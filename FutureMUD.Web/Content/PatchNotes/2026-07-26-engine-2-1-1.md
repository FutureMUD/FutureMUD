**Upgrade note:** Apply the normal database upgrades before starting Engine 2.1.1. This release keeps the .NET 10 and MySQL 8.0 requirements and the Windows x64, Linux x64 and Linux ARM64 package set from Engine 2.1.0.

## Spatial Areas And Builder Fixes

- Added support for version 3 spatial-area packages.
- Spatial-area packages can now omit installed door items where those items are not required by the package.
- Corrected the spatial-area `show` workflow so it presents the intended area details.

## World Simulation

- Fixed an issue when adding gas to the world.

See `/downloads` for release archives and checksums, `/getting-started` for installation requirements, and `/docs` for the published Engine reference.
