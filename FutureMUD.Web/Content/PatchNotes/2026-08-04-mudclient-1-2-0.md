---
title: FutureMUD Web MUD Client 1.2.0
summary: Adds signed, configuration-preserving automated upgrades and rollback for Web MUD Client operators.
date: 2026-08-04
tags: mudclient, release, upgrade
---

Web MUD Client 1.2.0 adds supported in-place upgrades for Windows, Linux x64, and Linux ARM64. A one-time migration preserves existing proxy and browser settings, keeps Caddy configuration stable, and converts the install to versioned releases with local rollback.

Routine administrator-initiated upgrades now verify a signed release manifest and archive checksum, stage the new release, restart only the private proxy, and restore the previous release automatically when its health check fails. Two previous releases are retained locally.
