**Requirements:** .NET 10 and MySQL 8.0. Framework-dependent packages target Windows x64, Linux x64 and Linux ARM64.

Engine 2.16.1 replaces the unpublished 2.16.0 release. It includes the [2.16.0 gameplay and building changes](/patch-notes/engine-2-16-0), including optional clothing fit, health policies, equipment bonuses, companion lifecycle controls and AI storyteller improvements.

## Corrections

- Climbing aids now expose their named prototype capability, and equipment bonus providers expose an aggregate capability matching their existing runtime behaviour. Component audits account for both registrations and their source-specific seeder ownership.
- Delayed location hints are explicitly classified as unsupported for stored scroll delivery. Their existing ordinary casting and configured magical-substance support is unchanged.
- Database upgrades recognise saved delayed location hints and preserve their remembered room, body identity, range and deadline.

This release also includes the optional character-creation skipper screens and assignment progs added after the 2.16.0 release candidate. Games must configure these screens and their eligibility rules before using them.

## Upgrading

Back up the database, configuration and external files, stop the old engine, and apply the normal database upgrades before reopening the world. Rehearse the upgrade and a cold restart against a copy of the database. The release-audit corrections introduce no additional database migration beyond the changes already included in 2.16.0.
