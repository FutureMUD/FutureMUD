title: FutureMUD Item Seeder 1.0.0
date: 2026-11-08
summary: The stock item catalogue is available as a separate product for existing FutureMUD worlds.
tags: item seeder, release, catalogue
---
FutureMUD Item Seeder is now distributed separately from the Database Seeder. Install it after creating your world and installing its required foundational packages, or use it later to update supported stock item content. The Item Seeder checks its prerequisites against the existing database before it starts.

This release preserves item identities and ownership records used by the former bundled catalogue. Existing worlds can use the standalone Item Seeder to reconcile supported stock items while retaining builder customisations.

Download the Item Seeder for Windows x64, Linux x64, or Linux ARM64 from the [downloads page](/downloads).
