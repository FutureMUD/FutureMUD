**Compatibility:** Use Item Seeder 1.0.0 with the Engine 2.17.0 and Database Seeder 3.9.0 schema. Framework-dependent packages require .NET 10 and MySQL 8.0 and target Windows x64, Linux x64 and Linux ARM64.

## A separate optional product

The stock item catalogue is now an independently versioned product. Install it after Database Seeder has created your world and installed its required foundations, or use it later to update supported stock item content. Item Seeder checks schema compatibility and package prerequisites before installation.

The Items package requires Core, Kickstart with Standard Item Components, and Animal Seeder foundations, or equivalent world records. Selected content may need additional foundations; the installer reports missing prerequisites and names the relevant Database Seeder package.

## Existing worlds and supported updates

This release preserves item identities and ownership records used by the former bundled catalogue. Existing worlds can reconcile supported stock items without installing a second copy of the catalogue.

Untouched stock definitions can be repaired while builder-customised aggregates and additions are preserved and reported. Ambiguous untracked identities block installation for review. Supported additional catalogue selections can be installed without removing previously installed content.

Version 1.0 covers the supported catalogue; planned catalogue expansions remain ongoing. Primary Production remains disabled.

## Armageddon content

Armageddon setting content and the historical Worldfile installer have moved into their own separate product. Interested parties should contact Japheth for information about the Armageddon product.

Download the Item Seeder for Windows x64, Linux x64, or Linux ARM64 from the [downloads page](/downloads).
