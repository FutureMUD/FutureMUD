date: 2026-11-25
tags: discord-bot, release, upgrade
---

Install .NET 11 and **upgrade the Bot before upgrading to Engine 2.18.0**. The new bot accepts notifications from the older Engine during the transition. The new remote commands become available with the upgraded Engine and its database migration. Install the Discord application with application-command permission.

- Use the new `/game`, `/account`, `/admin`, `/economy` and `/hooks` command groups for published game information, private account and application status, staff actions, economy reports and builder-published FutureProg actions.
- Existing bot-only account links need in-game ownership confirmation. Use the existing prefix registration command while connected and accept the proposal in game. Staff operations use the linked account’s game permissions. Sensitive replies are private, and changes such as a resource award require confirmation.
