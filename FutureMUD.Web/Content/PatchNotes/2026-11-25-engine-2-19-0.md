## Character creation

- Builders can use `NoteSkipper` to let applicants submit without a background note. Switching to it preserves notes an applicant has already entered.
- Builders can reserve the interactive disfigurement picker for special applications. Simple and normal applications skip that screen, while special applicants can choose scars, tattoos, missing body parts and configured prostheses at their usual costs. Existing disfigurement skippers keep their previous behaviour until a builder enables the option.
- Applications using `SkillSkipper` can now submit when their configured grants award zero skills. Required skill-group choices still apply.

## Discord integration

- Account creation sends an announcement to the configured admin channel. An accepted trial request, the start of a hearing and the launch of an execution patrol send announcements to that jurisdiction’s channel.
- The Engine now supplies court queues and judge availability, active patrols, NPC AI assignments and group rosters, and storyteller workload and failure reports. Authorised staff can also pause or resume a storyteller.
- Discord users can look up room landmarks. Public lookups evaluate visibility without an in-game character. For landmarks meant to be discovered in game, use a visibility prog that rejects a null character. A sphere label alone leaves a landmark visible on Discord.
- Linked Admins can subscribe to private alerts for reserve shortfalls and overdue economy snapshots. The Engine records each recipient’s open incidents so a continuing shortfall does not trigger repeated alerts.

**Upgrade order.** Games using Discord should install Discord Bot 1.8.0 before Engine 2.19.0. Back up the game database and apply the normal Engine upgrade. The new `20261125040236_AddDiscordEconomyRiskDigest` migration stores subscription and incident history. Existing and new account links start opted out.
