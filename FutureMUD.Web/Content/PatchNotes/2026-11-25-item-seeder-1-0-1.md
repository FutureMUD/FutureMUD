date: 2026-11-25
tags: item-seeder, release

Use this optional installer with the Engine 2.18.0 and Database Seeder 3.10.0 schema. Install .NET 11 before running it. Existing installations keep their stock catalogue identities and ownership records. The dependency refresh reproduced all 43,825 catalogue manifest entries.

Primary Production remains disabled in the public installer. Its project definitions now associate prospecting output with the matching discovery, for worlds working with that content. [Catalogue verification](https://github.com/FutureMUD/FutureMUD/blob/12729b8f1/Design%20Documents/Core/NuGet_Dependencies.md)
