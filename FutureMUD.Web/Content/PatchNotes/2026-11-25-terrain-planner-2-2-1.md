title: FutureMUD Terrain Planner & Engine API 2.2.1
summary: Refreshes the bundled runtime, database provider and update verifier for the Terrain Planner and Engine API.
date: 2026-11-25
tags: terrain-planner, release
---

The combined Planner and read-only Engine API now bundle .NET 11 and updated MySQL and package-verification libraries. The self-contained Windows x64, Linux x64 and Linux ARM64 packages include the runtime. Existing plans use the same project format and terrain-stack exports as 2.2.0.
