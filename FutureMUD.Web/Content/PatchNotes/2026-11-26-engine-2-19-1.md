## Restarting an existing game

- Games can boot with a saved corpse in a room. Once its original character has loaded, the Engine restores and activates items lodged in the corpse's wounds.
- Saving a character's accents during startup now preserves existing records and their preference and familiarity values. The Engine also records newly learned and forgotten accents.

Hosts upgrading from 2.19.0 can install the Engine and restart with their existing database. These fixes require no data repair or schema migration.

## Room descriptions and weather

- Builders can use `room preview` to see how a description reads under different light, time, season, wind and precipitation conditions. For example, `room preview time dusk rain dry recentrain heavyrain` shows the room at dusk after heavy rain.
- Room descriptions now handle negated season and time conditions correctly. Weather flavour echoes respect their configured interval, and builders can set a transition echo for a weather event whose name contains spaces.
