# Item Seeder

Use the repository instructions and open `ItemSeeder.sln` for catalogue development. The optional installer owns the Items package, its compiled catalogue and manifest tooling, and disabled Primary Production. Keep persisted seeder names, question IDs, aggregate keys, and ownership fingerprints compatible with worlds installed by Database Seeder.

Declare prerequisites against actual world records and identify the relevant Database Seeder package in the message. Keep reflection discovery local to this product. Update the item replay profiles when package or question contracts change. Item replay targets a prepared local Debug world. Verify changes with `ItemSeeder Unit Tests` and use the extended suite for affected catalogue parity or installer/rerun cases.
